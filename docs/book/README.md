# Learn You Some Heaven for Great Good

Tutoriel progressif pour Heaven, inspiré de
[Learn You a Haskell](https://learnyouahaskell.github.io),
[Learn You Some Erlang](https://learnyousomeerlang.com) et
[Structure and Interpretation of Computer Programs](https://mitpress.mit.edu/sites/default/files/sicp/full-text/book/book.html).

## Table des matières

1. [Starting Out](01-starting-out.md)
2. [Believe the Type](02-believe-the-type.md)
3. [Syntax in Functions](03-syntax-in-functions.md)
4. [Hello, Recursion!](04-recursion.md)
5. [Higher-Order Functions](05-higher-order.md)
6. [Effects](06-effects.md)
7. [Streams](07-streams.md)
8. [Proofs and Theorems](08-proofs.md)
9. [Real World](09-real-world.md)
10. [Under the Hood](10-under-the-hood.md)

## Prérequis

- Heaven installé (`zig build`)
- Un terminal ouvert sur `heaven repl`
- Un peu de curiosité
