TUTORIEL HEAVEN
===============

INSTALLATION
------------

1. Build natif :
   zig build

2. Build WASM :
   zig build wasm
   cp zig-out/bin/heaven.wasm src/vessel/public/

3. Lancer le REPL :
   rlwrap ./zig-out/bin/heaven 8080

EXEMPLE 1 : FACTORIELLE
------------------------

1. Définir la fonction :

   heaven> factorial zero = succ zero
   → factorial clause (1 patterns) registered

   heaven> factorial (succ n) = mul (succ n) (factorial n)
   → factorial clause (1 patterns) registered

2. Tester :

   heaven> factorial (succ (succ (succ zero)))
   → 6

EXEMPLE 2 : ADDITION
--------------------

1. Définir la fonction :

   heaven> add zero n = n
   → add clause (2 patterns) registered

   heaven> add (succ n) m = succ (add n m)
   → add clause (2 patterns) registered

2. Tester :

   heaven> add (succ (succ zero)) (succ (succ (succ zero)))
   → 5

EXEMPLE 3 : TRANSFORM
---------------------

1. Déclarer un théorème :

   heaven> theorem add_zero : a + 0 = a
   → theorem add_zero stated

2. Transformer :

   heaven> transform x + 0 = x
   → Success:
       Result: Refl
       Certificate: 3 steps

3. Échec explicite :

   heaven> transform x + 0 = y
   → Failure: StepFailed

EXEMPLE 4 : KNOWLEDGE ET RAISONNEMENT RDF
-----------------------------------------

Heaven possede une couche Knowledge distincte du langage executable.

Une connaissance RDF est representee comme un triple :

   sujet  predicat  objet

Exemple conceptuel :

   A subClassOf B
   B subClassOf C

Le reasoner RDFS peut alors produire :

   A subClassOf C

La nouvelle assertion est `inferred`. Les assertions originales restent
dans le KnowledgeStore avec leur provenance.

Important :

   Knowledge != Expr

Knowledge n'est pas un second IR de compilation. Si une connaissance
doit participer a un calcul Heaven, un lowering explicite vers `Expr`
sera necessaire.

Le POC actuel implemente :

- URI ;
- blank nodes ;
- literals ;
- triples ;
- provenance ;
- status `asserted/imported/derived/inferred/certified` ;
- confidence `low/medium/high` ;
- KnowledgeStore ;
- `rdfs:subClassOf` transitif.

Pas encore :

- Turtle ;
- SPARQL ;
- OWL ;
- `rdf:type` ;
- domain/range RDFS.

Le code du POC se trouve dans `src/knowledge/`.
